# Ahmad Azeem Academic Portfolio

Personal academic website for Ahmad Azeem, a Master of Science student in Structural and Material Engineering at National Yang Ming Chiao Tung University and PhD applicant in Geotechnical Engineering and related fields.

## Website Overview

The site presents Ahmad's academic profile, education, research experience, publications, projects, skills, professional experience, awards, CV, and contact information. It is designed for professors, researchers, and potential PhD supervisors.

## Run Locally

Open `index.html` in a browser. No backend or build step is required.

## Deploy With GitHub Pages

1. Create a GitHub repository named `Ahmadazeem73.github.io`, or use another repository and enable GitHub Pages from its settings.
2. Upload all website files to the repository.
3. Go to `Settings` → `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and `/root` folder.
6. Save and wait for GitHub Pages to publish the site.

Your profile site will be available at:

```text
https://Ahmadazeem73.github.io
```

## Customization Guide

- Replace `assets/images/profile-avatar.png` with a professional headshot when available.
- Update Google Scholar, ResearchGate, or ORCID links in `contact.html` after creating those profiles.
- Add new papers in `publications.html`.
- Add new research summaries in `research.html` and `projects.html`.
- Replace `assets/documents/Ahmad_Azeem_CV.pdf` whenever the CV is updated.
